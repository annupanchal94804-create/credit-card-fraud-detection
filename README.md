# Credit Card Fraud Detection

This project classifies credit card transactions as fraud or genuine using a machine learning model.

## Dataset
The Kaggle credit card fraud dataset was used, which contains transaction details along with a fraud/genuine label.

## Approach
1. Data cleaning and preprocessing was done
2. A model was trained to make predictions
3. Model performance was evaluated using accuracy, precision, and recall

## How to Run
1. Clone the repo
2. Open the notebook (app.ipynb)
3. Run all the cells

## Tools Used
Python, Pandas, Scikit-learn
